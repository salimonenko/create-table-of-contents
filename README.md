# create-table-of-contents

Скрипт создает ищет в HTML-коде вебстраницы тег с id="content_razn", в нем ищет теги, удовлетворяющие двум условиям:
1. Тег ДОЛЖЕН иметь полужирное выделение (степень жирности выше 400),
2. в начале текстового содержимого тега ДОЛЖЕН присутствовать символ параграфа ( § ).
Скрипт берет их текстовое содержимое (контент) и создает из этого оглавление. Панель с оглавлением располагается наверху справа страницы. Пример работы скрипта - здесь: http://4846d.ru/raznoe/pomoyka-ssha.html

Скрипт является кроссбраузерным, проверена работа в браузерах Firefox 24.
